# wechat-quality-checker

> 检测微信公众号文章/贴图内容质量，依据平台低创作度规范逐条排查，自动生成风格匹配的修订版。

A WorkBuddy skill that detects low-quality WeChat Official Account (微信公众号) articles and generates style-matched revisions based on the platform's low-creativity content guidelines.

---

## 为什么需要这个工具

微信公众平台对"低创作度内容"有限流机制，但平台规范是文字描述，创作者很难逐条自查。这个技能把 4 条规范转化为可执行的检测流程，帮你：

- 发布前自查文章是否会触发低质量限流
- 发现文章的信息量短板并获得具体修改建议
- 获得保留你个人文风的修订版，而不是机器味的改写

## 核心能力

### 4 维度质量检测

| 维度 | 检测内容 |
|------|----------|
| 同质化内容 | 选题/结构/表述是否与历史文章高度雷同 |
| 搬运/抄袭/洗稿 | 引用占比、来源标注、核心内容来源 |
| 信息量不足 | 结论完整性、信息具体性、信息密度、可操作性、信息增量对比、篇幅匹配度 — 6 个子维度评分 |
| 低价值 AIGC | 模板化结构、空泛表述、个人经验缺失、批量特征 |

### 风格匹配的修订版

修订前先提取原文的 6 个风格维度（语气口吻、句式习惯、叙事节奏、互动方式、用词偏好、段落长度），修订版严格复刻原文风格，不引入原文没有的文风。

### 段落字数约束

修订版每段不超过 150 字（含标点），适合手机端阅读，不会出现大段文字堆砌。

### 贴图检测

支持纯图片贴图内容检测，区分表情包、工具截图、原创设计图，给出针对性建议。

## 安装

### 方式一：WorkBuddy 技能市场（推荐）

在 WorkBuddy 中直接安装（如果已上架）。

### 方式二：手动安装

将本仓库克隆到 WorkBuddy 技能目录：

```bash
# 用户级（跨项目可用）
git clone https://github.com/Rutake/wechat-quality-checker.git ~/.workbuddy/skills/wechat-quality-checker

# 项目级（仅当前项目）
git clone https://github.com/Rutake/wechat-quality-checker.git .workbuddy/skills/wechat-quality-checker
```

安装后，在 WorkBuddy 对话中发送文章链接或文本，提及"检查文章质量""公众号检测""低质量内容"等关键词即可触发。

## 使用方式

### 检查单篇文章

直接发送微信文章链接：

```
帮我检查一下这篇公众号文章的质量
https://mp.weixin.qq.com/s?...
```

或直接粘贴文本：

```
帮我检测这段文章是否符合公众号规范
（粘贴正文）
```

### 批量检查多篇文章

连续发送多个链接，技能会逐篇检测后追加横向对比表，帮你识别整体内容质量趋势。

### 获取修订版

检测发现问题后，说"帮我改一下"即可获得风格匹配的修订版。

## 输出示例

检测报告格式：

```
| 条款 | 是否触发 | 风险等级 |
|------|---------|---------|
| (1) 同质化内容 | 边界 | ⚠️ 低~中 |
| (2) 搬运/抄袭 | 否 | — |
| (3) 信息量不足 | 是 | 🔴 高 |
| (4) 低价值 AIGC | 否 | — |
```

修订版附带改动说明表：

```
| 改动点 | 原文 | 修订版 | 为什么改 |
|--------|------|--------|----------|
| 例证词汇 | apple/water | reluctant/overwhelmed | 基础词无法体现英英释义价值 |
```

更多示例见 [`examples/`](examples/)。

## 检测标准依据

依据微信公众平台官方"低创作度内容"规范，平台鼓励具有丰富信息含量的内容，欢迎为用户提供信息增量或情绪价值等价值的内容。低创作度内容不适合推荐，包括：

1. 同质化内容，频繁发布高度相似内容，缺乏信息增量
2. 搬运、抄袭、洗稿，或大篇幅引用他人创作内容，或重复发布同一内容，整体创作度低
3. 信息量不足，疑似无法为用户提供有效价值的低信息量内容
4. 低价值 AIGC 内容

## 适用场景

- 公众号创作者发布前自查
- 内容团队批量审核文章质量
- 新媒体运营排查文章被限流的原因
- AI 辅助创作后的人工质检环节
