# 微信公众平台低创作度内容判定标准

## 来源

依据微信公众平台官方规范，平台鼓励具有丰富信息含量的内容，欢迎为用户提供信息增量或情绪价值等价值的内容。低创作度内容不适合推荐。

以下为 4 条标准的详细判定维度和边界案例，供检测时参考。

---

## 条款一：同质化内容

### 定义

频繁发布高度相似内容，缺乏信息增量。

### 判定维度

| 维度 | 说明 |
|------|------|
| 选题重复 | 多篇文章围绕同一话题，且未提供新角度 |
| 结构雷同 | 文章结构模板化（如每次都是"发现问题→尝试→解决"的相同叙事弧线） |
| 表述相似 | 跨文章存在大量重复用词和句式 |
| 信息重叠 | 新文章未提供超出历史文章的新信息 |

### 单篇检测局限性

单篇文章无法判定同质化。检测时：
- 若仅提供单篇：标注"单篇无法判定，建议自查历史文章"
- 若提供多篇：做横向对比，识别共性问题

### 不触发的情况

- 系列文章：同一系列下每篇有独立信息增量
- 话题深耕：同一话题但从不同角度深入分析

---

## 条款二：搬运、抄袭、洗稿

### 定义

搬运、抄袭、洗稿，或大篇幅引用他人创作内容，或重复发布同一内容，整体创作度低。

### 判定维度

| 维度 | 说明 |
|------|------|
| 引用占比 | 引用他人内容的篇幅占全文比例 |
| 来源标注 | 引用是否标注出处 |
| 核心内容来源 | 文章核心观点/信息是否来自他人创作 |
| 改写程度 | 是否仅做表层改写（换词、调序）而保留原结构和信息 |

### 合理引用（不触发）

- 标注了来源
- 引用篇幅占全文比例低（通常 < 20%）
- 引用用于支撑自己的论点，而非构成文章主体

### 触发的情况

- 全文核心内容来自一篇文章，仅做换词改写
- 大段复制他人内容未标注来源
- 重复发布自己已发过的内容（非修订版）

---

## 条款三：信息量不足

### 定义

疑似无法为用户提供有效价值的低信息量内容。

### 核心判定原则

**读者看完后是否获得了有效价值？** 如果读者看完后无法执行任何操作、无法获得任何超出搜索引擎第一条结果的信息，则信息量不足。

### 详细评分维度

#### 维度一：结论完整性

| 情况 | 风险 |
|------|------|
| 文章有明确结论，读者可获得确定信息 | ✅ 安全 |
| 文章有倾向性结论，附带不确定性说明 | ✅ 安全 |
| 文章以"没搞懂""不确定"收尾，无任何可操作建议 | ⚠️ 风险 |

#### 维度二：信息具体性

| 情况 | 风险 |
|------|------|
| 说明了具体工具名、操作步骤、适用场景 | ✅ 安全 |
| 概念性描述但未指向具体对象 | ⚠️ 风险 |
| 关键信息全部模糊化（"某软件""某方法""某个操作"） | 🔴 高风险 |

#### 维度三：信息密度

| 情况 | 风险 |
|------|------|
| 每段都有可提取的有效信息 | ✅ 安全 |
| 部分段落为纯叙事过渡，但整体信息密度尚可 | ⚠️ 边界 |
| 大量篇幅为"还是不行""没有用""突然好了"的过程描述 | 🔴 高风险 |

#### 维度四：可操作性

| 情况 | 风险 |
|------|------|
| 读者看完后能执行具体操作 | ✅ 安全 |
| 读者获得了一个方向但不知道怎么落地 | ⚠️ 边界 |
| 读者看完后无法执行任何行动 | 🔴 高风险 |

#### 维度五：信息增量对比

| 对比基准 | 判定 |
|----------|------|
| 搜索引擎第一条结果是否已包含这些信息 | 若是，信息增量低 |
| 工具官方介绍是否已包含这些信息 | 若是，信息增量低 |
| 常识性知识是否已包含这些信息 | 若是，信息增量低 |

#### 维度六：篇幅与信息量匹配

| 字数 | 信息量 | 判定 |
|------|--------|------|
| < 100 字 | 低 | 🔴 几乎必然触发 |
| 100-300 字 | 低 | 🔴 高风险 |
| 300-500 字 | 中 | ⚠️ 边界，取决于信息密度 |
| 500+ 字 | 中-高 | ✅ 通常安全 |
| 500+ 字 | 低（信息被稀释） | ⚠️ 风险 |

### 常见误判

| 误判 | 实际情况 |
|------|----------|
| 短文章一定信息量不足 | 不一定，若有高密度有效信息则安全 |
| 长文章一定安全 | 不一定，若信息被大量叙事稀释仍有风险 |
| 有图片就安全 | 不一定，截图无文字解读仍可能信息量不足 |

## 条款四：低价值 AIGC 内容

### 定义

平台支持新技术辅助创作但不鼓励借用新技术直接生成、批量制造低信息量内容。

### 判定维度

| 维度 | 说明 |
|------|------|
| 模板化结构 | 是否为典型 AI 输出结构（总分总、首先其次最后） |
| 空泛表述 | 是否大量使用"具有重要意义""值得关注"等空话 |
| 个人经验缺失 | 是否缺乏具体个人经历、情感、判断 |
| 批量特征 | 是否像批量生成的流水线内容 |

### 不触发的情况

- 人工使用 AI 辅助，但有实质个人观点和经验
- AI 生成初稿后人工深度修改，有个人风格
- 技术性内容（代码、数据分析）使用 AI 辅助但有人工验证

### 触发的情况

- 直接粘贴 AI 输出，无任何二次加工
- 批量生成同主题文章，每篇仅微调
- AI 生成的空泛内容，无具体信息和操作价值

## 风险等级参考

| 等级 | 含义 | 建议 |
|------|------|------|
| 🔴 高 | 几乎必然被判定为低质量 | 必须修订后再发布 |
| ⚠️ 中 | 大概率被判定，审核严时触发 | 建议修订 |
| ⚠️ 低~中 | 边界情况，审核宽松时安全 | 可选修订 |
| — | 不触发 | 无需处理 |

---

## 修订策略速查

| 触发条款 | 修订策略 |
|----------|----------|
| 条款一（同质化） | 换角度、换案例、提供新信息增量 |
| 条款二（搬运） | 减少引用比例、标注来源、增加原创分析 |
| 条款三（信息量） | 补结论、补实例、补操作步骤、删空泛段落 |
| 条款四（AIGC） | 增加个人经验、口语化改写、打破模板结构 |

---

## 修订版风格与格式约束

### 风格复刻

修订前必须先提取原文风格特征，修订版严格复刻，不引入原文没有的文风。

提取维度：

| 维度 | 提取内容 | 示例 |
|------|----------|------|
| 语气与口吻 | 正式/口语化/幽默/平实；自称和称呼方式 | "小编""各位朋友" |
| 句式习惯 | 短句/长句；问句频率；连接词偏好 | 短句为主，爱用问句引导 |
| 叙事节奏 | 平铺直叙/先抛问题/先给结论 | 先抛问题，逐步展开 |
| 互动方式 | 是否向读者提问，提问语气 | 结尾习惯问"不知道大家..." |
| 用词偏好 | 书面/口语；网络用语；模糊表达 | "感觉""挺"等口语词 |
| 段落长度 | 原文段落平均字数 | 平均30-50字/段 |

### 段落字数硬约束

- 每一段不超过 150 字（含标点符号）
- 原文段落如超出 150 字，修订时拆分为多段
- 新增内容也必须遵守此限制
- 长内容用多个短段落 + 小标题组织，不要用超长段落堆砌
- 检查方法：修订完成后逐段数字数，超出的段落继续拆分直到达标
